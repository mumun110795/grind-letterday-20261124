## About this entry

This entry is exactly one character: a single letter, and nothing
else. The letter is C, for coffee — the word that most honestly
describes a long working Tuesday. Not ambition, not inspiration:
just cup after cup, the third one poured before the morning is
half done, quietly carrying the whole day. Running the program
writes that one letter, as plain UTF-8 text, to `entry.txt`.

The program keeps the letter as a constant, checks that it really
is exactly one character from A to Z, creates the output directory
if needed, and writes the file.

## Run it

```sh
node main.ts
```

By default the letter is written to `/output/entry.txt`. Set
`OUTPUT_DIR` to write somewhere else:

```sh
OUTPUT_DIR=/tmp/test-out-letterday node main.ts
```
